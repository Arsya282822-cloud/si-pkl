## 2. BERITA ACARA SERAH TERIMA SISTEM (BAST)

Pada hari ini, ..................... Tanggal .......... Bulan ......................... Tahun Dua Ribu Dua Puluh Enam (2026), bertempat di SMK Labor Binaan FKIP UNRI Pekanbaru, telah dilakukan serah terima hasil pengembangan perangkat lunak sistem informasi antara:

1. **Nama**: Tim Pengembang SI-PKL  
   **Status**: Pengembang Perangkat Lunak (*Developer*)  
   *Selanjutnya disebut sebagai **PIHAK PERTAMA (Yang Menyerahkan)**.*

2. **Nama**: Dedi Hendrawan, S.Kom., M.Kom.  
   **Jabatan**: Ketua Pokja PKL / Hubungan Industri SMK Labor Binaan FKIP UNRI  
   *Selanjutnya disebut sebagai **PIHAK KEDUA (Yang Menerima)**.*

### PASAL 1: OBJEK SERAH TERIMA
PIHAK PERTAMA menyerahkan kepada PIHAK KEDUA satu unit sistem aplikasi terintegrasi dengan rincian sebagai berikut:
1. **Nama Aplikasi**: Sistem Informasi Praktik Kerja Lapangan (SI-PKL).
2. **Teknologi**: Laravel 11 Framework, Progressive Web App (PWA), HTML5 Geolocation API, Chart.js Analytics.
3. **Komponen yang Diserahkan**:
   - Source Code Lengkap Aplikasi SI-PKL.
   - Database Aplikasi (Struktur Skema & Data Master).
   - Buku Petunjuk Penggunaan (*User Manual Guide*).
   - Akun Akses Administrator Pokja PKL.

### PASAL 2: KELAIKAN SISTEM
PIHAK KEDUA telah melakukan pengujian fungsional (*User Acceptance Testing*) dan menyatakan bahwa seluruh fitur sistem (Presensi GPS, Jurnal Harian Siswa, Validasi Guru, Berkas Observasi, Analitik Dashboard, dan Generator Rapor Kurikulum Merdeka) telah berjalan dengan baik dan laik digunakan untuk operasional PKL sekolah.

Demikian Berita Acara Serah Terima ini dibuat dengan sebenarnya dalam rangkap 2 (dua) untuk dipergunakan sebagaimana mestinya.
